System Architecture

Engineered for local speed, not cloud bloat.

Every action reads and writes directly to a local SQLite database on your machine—delivering sub-millisecond transitions even without Wi-Fi.

Local-First Engine 0ms Network Wait

Direct SQLite storage on your disk.

DewTask never holds your projects hostage behind a mandatory web login. Your entire workspace hierarchy lives inside a standard SQLite file that you can inspect, back up, or version-control anytime.

LOCAL DATABASE PATH ● READ/WRITE LOCAL

Native Runtime Rust + Tauri

Lightweight Windows footprint.

By pairing a Rust backend with Tauri instead of bundling a full Chromium browser, DewTask launches cold in a fraction of a second and stays light on RAM.

Product Philosophy

Software you install once and truly own.

Modern task managers have turned simple checklists into sluggish web wrappers with mandatory subscriptions and opaque cloud databases. DewTask returns to the craft of native desktop software.

01 / LOCAL BY DEFAULT

No mandatory accounts

Download, launch, and start organizing immediately. Your data stays on your machine unless you opt into sync.

02 / BRING YOUR OWN CLOUD

Direct Google Drive sync

Optional sync connects straight to your personal Google Drive appDataFolder—no middleman servers.

03 / OPEN FORMAT

Standard SQLite schema

Your tasks live in a clean, portable `.db` file you can query, back up, or migrate at will.

04 / OPEN SOURCE

Auditable codebase

Inspect the Rust & TypeScript source on GitHub, verify privacy guarantees, or build from source.
